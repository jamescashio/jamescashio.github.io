# First Light · Signal polish

Prepared on 11-01-2026 as an isolated preview of the published First Light presentation. This new round awaits final publication approval.

Mission Control becomes a visual index to the eleven existing destinations. Explore, Try, Watch and Connect filters work together with search. Descriptive rows and a desktop artwork preview help visitors choose a destination; arrow keys, Home, End and Enter support keyboard navigation. An empty search offers a reset that clears both filters. Opening the menu resets the index and scroll position, Escape closes it, and focus returns to its opener. Artwork previews compact themselves for shorter laptop windows. Phones retain a compact list with reachable search, close and motion controls. Hidden phone artwork is not requested.

The world atlas gains an authored vector globe, orbital tick marks and a small route illustration on phones. The four existing world tabs, descriptions, original artwork, interactive routes and reading editions remain. The illustration is decorative navigation art, not a representation of live systems.

House Cashio gains a segmented aperture play icon, frame corners and a brief light response on hover or keyboard focus. Its poster, 61 second film, captions, text version, quiet native player and bookmarks are unchanged. Navigation previews never start or download a film.

New movement lasts at most 650 milliseconds. Reduced motion, Pause motion and background visibility controls preserve a complete static presentation. The new menu artwork animation cancels when the menu closes or motion is paused. Existing hero, sound and media policies remain in effect.

All existing public files, observations, historical releases, media and captions remain byte for byte unchanged. No new dependency or external service is introduced. Secondary presentation styles remain deferred; the compressed entry CSS budget stays at 19,000 bytes. The current observation is still the verified 10-31-2026 record.

Verification covers the destination filters, empty-state recovery, keyboard navigation, phone fit, accessible controls, reduced motion, playback, all original routes and content preservation. The existing navigation lifecycle harness loads the real new menu module so it continues testing the same scroll-restoration and interruption contracts.
