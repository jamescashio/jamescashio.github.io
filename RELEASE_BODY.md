# V40.0.2 Mostly Harmless

The front door opens on a new 36 second arrival film rendered from code: a sunrise over a ringed world, the fleet passing in formation and a starship flyby, built from real 3D models in the same browser pipeline that produced the V40 reel. The hero plays the film once per browser session, then hands off to the ringed horizon loop; later visits in the same session open on the loop. Watch the intro replays the full cut in the cinema, and the score and narration stay opt in through the player controls.

Bit, the cinematic V40 design, all seven experiments, and every original media file remain intact. The Helios arrival film stays on disk for the V39 edition. V39 remains available at `/v39/`.

Validation covers the hero handoff, the once per session gate with session storage unavailable, the cinema replay, reading mode, keyboard access, reduced motion, and all existing V40 interactions. Publication uses the existing protected review and deployment checks.
